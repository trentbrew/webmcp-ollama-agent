WebMCP test page

This page has no native document.modelContext, so it installs a minimal shim matching the spec's shape (registerTool / getTools / toolchange event), then registers three tools for testing the webmcp extension's side panel:

  • echo(message) — returns { echoed: message }
  • add(a, b) — returns { sum: a + b }
  • boom() — always throws, to test error-trace handling

Open the extension's side panel, go to the MCP tab, and confirm the tools show up.
